# NameWall

The investments, as a wall of names set in Syne on the contrast band. No logos, no descriptions; those live on /profile/.

- The band always takes the opposite theme: paper in dark mode, pine in light mode. Inside it, everything uses theme tokens.
- `names` style (Syne 600, -0.035em), `--fg`, flex-wrap with a .18em by .62em gap.
- Exits carry a superscript "Exit" in `label` caps, `--accent` (brass-ink on paper, brass on pine). The buyers go in the section note, not the wall.
- Hover (pointer devices): every other name fades to 26% opacity, so the hovered one stands alone.
- The consumer provides names, URLs and which ones exited. The preview shows the dark-mode band (paper).
