# Figure

A single headline number with a one-line caption. Three per page, never more, each a fact a reader could verify.

- Number in `figure` (Syne 600, -0.055em, tabular), `sage`. Caption in `caption`, `sage-muted`, max 27ch, written as the rest of a sentence ("in Spotify subscription revenue under my responsibility"). Attribute each number exactly: the 60% is the Global Growth team, the $1B+ is Sven's own revenue responsibility.
- A `sage-rule` hairline sits on top of each figure.
- On enter, the number rises out of a clip over 1.3s. No count-up.
- The consumer provides the value string and the caption.
