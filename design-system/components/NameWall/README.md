# NameWall

The investments, as a wall of names set in Syne on the paper band. No logos, no descriptions; those live on /profile/.

- `names` style (Syne 600, -0.035em), `ink`, flex-wrap with a .18em by .62em gap.
- Exits carry a superscript "Exit" in `label` caps, `brass-ink`. The exit buyers go in the section note, not the wall.
- Hover (pointer devices): every other name fades to 26% opacity, so the hovered one stands alone.
- The consumer provides names, URLs and which ones exited.
